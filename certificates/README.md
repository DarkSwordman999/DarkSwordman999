## Проверка целостности

Контрольная сумма SHA-256 оригинала — совпадает с файлом, полученным на Госуслугах:

| Файл | SHA-256 |
|---|---|
| `it-competence-postgresql.pdf` | `24bac463fa56b8e2bcb8de7444050df71974f6c35f9d782bb98d9daecb4f17f5` |

Проверить у себя: `sha256sum it-competence-postgresql.pdf` (Linux, Git Bash) или `Get-FileHash it-competence-postgresql.pdf` (PowerShell).

Файлы `*.pdf`, `*.sig` и `*.p7s` помечены в [`.gitattributes`](../.gitattributes) как бинарные: Git хранит и отдаёт их байт в байт.
